# StatMate — Statistics Calculator

A mobile-friendly statistics calculator for mean, median, mode, variance, standard deviation and basic descriptive statistics.

## Free hosting with GitHub Pages

1. Create/sign in to a GitHub account.
2. Create a **new public repository** named `statmate-calculator`.
3. Upload all files in this folder to the repository root:
   - `index.html`
   - `manifest.json`
   - `service-worker.js`
   - `icon-192.png`
   - `icon-512.png`
4. Open the repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then click **Save**.
7. Wait a few minutes. GitHub will show a **Visit site** link.
8. Send that link to your teacher. It works in a phone browser.

The project is client-side: calculations happen in the browser and no dataset is uploaded.
