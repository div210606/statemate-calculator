Formulas

Mean = Σx / n Variance (population) = Σ(x − mean)² / n Variance (sample) = Σ(x − mean)² / (n − 1) Standard deviation = √variance

How to use

3 simple steps

1. Enter data

Type numbers separated by commas, spaces, semicolons or new lines.

2. Choose dataset type

Use Population for a complete dataset or Sample when your data represents a sample.

3. Read your results

The app calculates mean, median, mode, variance, standard deviation and other useful measures.
